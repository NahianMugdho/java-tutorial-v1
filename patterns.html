৩. প্যাটার্ন প্রোগ্রাম (Pattern Programs)

3. Pattern Programs

৩.১ Right Triangle (*)

মনে রাখার কৌশল: বাইরের লুপ সারি, ভিতরের লুপ কলাম — সারি নাম্বার অনুযায়ী * প্রিন্ট করো।
Memory Tip: Outer loop = rows, inner loop = columns. Print * equal to row number.
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++)
                System.out.print("* ");
            System.out.println();
        }
    }
}

৩.২ Inverted Triangle

মনে রাখার কৌশল: বাইরের লুপ n থেকে 1 পর্যন্ত কমতে থাকবে।
Memory Tip: Outer loop decreases from n to 1.
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int i = n; i >= 1; i--) {
            for (int j = 1; j <= i; j++)
                System.out.print("* ");
            System.out.println();
        }
    }
}
* * * * * * * * * * * * * * *

৩.৩ Pyramid

মনে রাখার কৌশল: প্রথমে স্পেস (n-i বার), তারপর স্টার (2*i-1 বার)।
Memory Tip: First print spaces (n-i times), then stars (2*i-1 times).
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int i = 1; i <= n; i++) {
            for (int s = 1; s <= n - i; s++) System.out.print(" ");
            for (int j = 1; j <= 2 * i - 1; j++) System.out.print("*");
            System.out.println();
        }
    }
}

৩.৪ Floyd's Triangle

মনে রাখার কৌশল: একটি কাউন্টার (num) রাখো যেটা প্রতিটি প্রিন্টে ১ করে বাড়বে।
Memory Tip: Keep a counter that increments on every print.
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5, num = 1;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++)
                System.out.print(num++ + " ");
            System.out.println();
        }
    }
}

৩.৫ Pascal's Triangle

মনে রাখার কৌশল: প্রতিটি সংখ্যা = উপরের দুইটার যোগফল। সূত্র: val = val * (i-j) / (j+1)
Memory Tip: Each number is sum of two above. Formula: val = val * (i-j) / (j+1)
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int i = 0; i < n; i++) {
            int val = 1;
            for (int s = 0; s < n - i - 1; s++) System.out.print(" ");
            for (int j = 0; j <= i; j++) {
                System.out.print(val + " ");
                val = val * (i - j) / (j + 1);
            }
            System.out.println();
        }
    }
}

৩.৬ Number Pattern

মনে রাখার কৌশল: ভিতরের লুপে j নিজেই প্রিন্ট হয় (1,2,3...i)।
Memory Tip: Inner loop prints j itself (1 to i).
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++)
                System.out.print(j + " ");
            System.out.println();
        }
    }
}

৩.৭ Alphabet Pattern

মনে রাখার কৌশল: 'A' + j করলে অক্ষর পাওয়া যায়। char + int = int হয়, তাই (char) cast লাগে।
Memory Tip: 'A' + j gives the letter. Cast to (char) because char + int becomes int.
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j <= i; j++)
                System.out.print((char) ('A' + j) + " ");
            System.out.println();
        }
    }
}
