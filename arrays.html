৪. অ্যারে প্রোগ্রাম (Array Programs)

4. Array Programs

৪.১ Largest & Smallest Element

মনে রাখার কৌশল: প্রথম এলিমেন্টকে max/min ধরে বাকিগুলোর সাথে তুলনা করো। সাইজ পেতে arr.length (ব্র্যাকেট ছাড়া)।
Memory Tip: Initialize max/min with first element. Use arr.length (no brackets).
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {12, 45, 2, 41, 31, 10};
        int n = arr.length;
        int mx = arr[0], mn = arr[0];
        for (int i = 1; i < n; i++) {
            if (arr[i] > mx) mx = arr[i];
            if (arr[i] < mn) mn = arr[i];
        }
        System.out.println("সবচেয়ে বড়: " + mx + ", সবচেয়ে ছোট: " + mn);
    }
}
সবচেয়ে বড়: 45, সবচেয়ে ছোট: 2

৪.২ Second Largest

মনে রাখার কৌশল: max ভাঙলে পুরনো max হবে second।
Memory Tip: When a new max is found, old max becomes second.
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {12, 45, 2, 41, 31, 10};
        int n = arr.length;
        int mx = arr[0], second = -1;
        for (int i = 1; i < n; i++) {
            if (arr[i] > mx) {
                second = mx;
                mx = arr[i];
            } else if (arr[i] > second && arr[i] != mx) {
                second = arr[i];
            }
        }
        System.out.println("দ্বিতীয় বৃহত্তম: " + second);
    }
}
দ্বিতীয় বৃহত্তম: 41

৪.৩ Reverse Array

মনে রাখার কৌশল: দুটি ইনডেক্স (start, end) দিয়ে swap করো।
Memory Tip: Use two indices (start, end) and swap until they meet.
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5};
        int n = arr.length;
        for (int i = 0, j = n - 1; i < j; i++, j--) {
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
        for (int i = 0; i < n; i++) System.out.print(arr[i] + " ");
        System.out.println();
    }
}

৪.৪ Bubble Sort

মনে রাখার কৌশল: পাশাপাশি দুইটা তুলনা করে বড়টাকে পিছনে ঠেলে দাও। বাস্তবে Arrays.sort(arr) ব্যবহার করো।
Memory Tip: Compare adjacent elements and bubble larger one to the end. Prefer Arrays.sort(arr) in practice.
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {5, 2, 9, 1, 5, 6};
        int n = arr.length;
        for (int i = 0; i < n - 1; i++)
            for (int j = 0; j < n - i - 1; j++)
                if (arr[j] > arr[j + 1]) {
                    int t = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = t;
                }
        for (int i = 0; i < n; i++) System.out.print(arr[i] + " ");
        System.out.println();
    }
}

৪.৫ Selection Sort

মনে রাখার কৌশল: প্রতি ধাপে বাকি অংশ থেকে সবচেয়ে ছোট index খুঁজে swap করো।
Memory Tip: Find the minimum in remaining part and swap with current position.
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {5, 2, 9, 1, 5, 6};
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            int minIdx = i;
            for (int j = i + 1; j < n; j++)
                if (arr[j] < arr[minIdx]) minIdx = j;
            int t = arr[minIdx];
            arr[minIdx] = arr[i];
            arr[i] = t;
        }
        for (int i = 0; i < n; i++) System.out.print(arr[i] + " ");
        System.out.println();
    }
}

৪.৬ Linear Search

মনে রাখার কৌশল: শুরু থেকে শেষ পর্যন্ত এক এক করে চেক করো — O(n)।
Memory Tip: Check every element from start to end — O(n).
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {5, 2, 9, 1, 5, 6};
        int n = arr.length, key = 9, found = -1;
        for (int i = 0; i < n; i++)
            if (arr[i] == key) { found = i; break; }
        if (found != -1) System.out.println(key + " পাওয়া গেছে index " + found + " এ");
        else System.out.println("পাওয়া যায়নি");
    }
}
9 পাওয়া গেছে index 2 এ

৪.৭ Binary Search

মনে রাখার কৌশল: অ্যারে sorted থাকতে হবে। মাঝের সাথে তুলনা করে অর্ধেক বাদ দাও — O(log n)।
Memory Tip: Array must be sorted. Compare with middle and discard half — O(log n).
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {1, 3, 5, 7, 9, 11, 13};
        int n = arr.length, key = 7;
        int low = 0, high = n - 1, found = -1;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (arr[mid] == key) { found = mid; break; }
            else if (arr[mid] < key) low = mid + 1;
            else high = mid - 1;
        }
        if (found != -1) System.out.println(key + " পাওয়া গেছে index " + found + " এ");
        else System.out.println("পাওয়া যায়নি");
    }
}
7 পাওয়া গেছে index 3 এ

৪.৮ Merge Two Arrays

মনে রাখার কৌশল: নতুন অ্যারেতে প্রথম + দ্বিতীয় অ্যারের সব উপাদান কপি করো।
Memory Tip: Create new array and copy all elements from both arrays.
Main.java
public class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3}, b = {4, 5, 6};
        int[] merged = new int[a.length + b.length];
        int k = 0;
        for (int i = 0; i < a.length; i++) merged[k++] = a[i];
        for (int i = 0; i < b.length; i++) merged[k++] = b[i];
        for (int i = 0; i < k; i++) System.out.print(merged[i] + " ");
        System.out.println();
    }
}

৪.৯ Matrix Addition

মনে রাখার কৌশল: একই position-এর (i,j) দুইটা এলিমেন্ট যোগ করো। 2D অ্যারে = অ্যারের অ্যারে।
Memory Tip: Add elements at same (i,j). 2D array is array of arrays.
Main.java
public class Main {
    public static void main(String[] args) {
        int[][] a = {{1,2},{3,4}}, b = {{5,6},{7,8}};
        int[][] c = new int[2][2];
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++)
                c[i][j] = a[i][j] + b[i][j];
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < 2; j++) System.out.print(c[i][j] + " ");
            System.out.println();
        }
    }
}

৪.১০ Matrix Multiplication

মনে রাখার কৌশল: তিনটা লুপ (i,j,k) — row × column, ভিতরে sum যোগ হবে।
Memory Tip: Three loops (i,j,k). Result[i][j] = sum of a[i][k] * b[k][j].
Main.java
public class Main {
    public static void main(String[] args) {
        int[][] a = {{1,2},{3,4}}, b = {{5,6},{7,8}};
        int[][] c = new int[2][2];
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++)
                for (int k = 0; k < 2; k++)
                    c[i][j] += a[i][k] * b[k][j];
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < 2; j++) System.out.print(c[i][j] + " ");
            System.out.println();
        }
    }
}

৪.১১ Matrix Transpose

মনে রাখার কৌশল: row আর column অদল-বদল — t[j][i] = a[i][j]
Memory Tip: Swap rows and columns: t[j][i] = a[i][j]
Main.java
public class Main {
    public static void main(String[] args) {
        int[][] a = {{1,2,3},{4,5,6}};
        int[][] t = new int[3][2];
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 3; j++)
                t[j][i] = a[i][j];
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 2; j++) System.out.print(t[i][j] + " ");
            System.out.println();
        }
    }
}
