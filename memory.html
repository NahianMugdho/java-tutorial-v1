10. Dynamic Memory → Memory Management in Java

১০.১ malloc() → new

মনে রাখার কৌশল: new দিয়ে হিপে মেমরি বরাদ্দ। new int[n] নিজে থেকেই ০ দিয়ে initialize হয়। delete লাগে না।
Memory Tip: new allocates on heap. new int[n] is zero-initialized. No delete needed.
Main.java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) arr[i] = i + 1;
        for (int i = 0; i < n; i++) System.out.print(arr[i] + " ");
        System.out.println();
    }
}

১০.২ calloc() equivalent

মনে রাখার কৌশল: new int[n] নিজেই সব 0 দিয়ে ভরে। অন্য মান চাইলে Arrays.fill()।
Memory Tip: new int[n] already fills with zeros. Use Arrays.fill() for other values.
Main.java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int n = 5;
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) System.out.print(arr[i] + " ");
        System.out.println();
        Arrays.fill(arr, 7);
        System.out.println(Arrays.toString(arr));
    }
}
0 0 0 0 0 [7, 7, 7, 7, 7]

১০.৩ realloc() → Arrays.copyOf / ArrayList

মনে রাখার কৌশল: অ্যারের আকার বদলানো যায় না। Arrays.copyOf() বা ArrayList ব্যবহার করো।
Memory Tip: Array size is fixed. Use Arrays.copyOf() or ArrayList for resizing.
Main.java
import java.util.ArrayList;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3};
        arr = Arrays.copyOf(arr, 5);
        arr[3] = 4;
        arr[4] = 5;
        for (int x : arr) System.out.print(x + " ");
        System.out.println();

        ArrayList list = new ArrayList<>(Arrays.asList(1, 2, 3));
        list.add(4);
        list.add(5);
        for (int x : list) System.out.print(x + " ");
        System.out.println();
    }
}

১০.৪ free() → Garbage Collection

মনে রাখার কৌশল: free/delete নেই। রেফারেন্সে null দিলে GC নিজে মেমরি ফ্রি করে। System.gc() শুধু hint।
Memory Tip: No free/delete. Set reference to null; GC reclaims memory. System.gc() is only a hint.
Main.java
public class Main {
    public static void main(String[] args) {
        int[] data = new int[1000];
        data[0] = 100;
        System.out.println("মান = " + data[0]);
        data = null;
        System.gc();
        System.out.println("অ্যারে আর ব্যবহার হচ্ছে না — মেমরি ফ্রি করবে Garbage Collector");
    }
}
মান = 100 অ্যারে আর ব্যবহার হচ্ছে না — মেমরি ফ্রি করবে Garbage Collector
