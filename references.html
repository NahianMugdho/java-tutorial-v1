৭. পয়েন্টার → Java তে রেফারেন্স

7. Pointers → References in Java

Java তে পয়েন্টার নেই — & , * , -> এবং pointer arithmetic কিছুই নেই। এর বদলে আছে রেফারেন্স ও index।

Java has no pointers — no &, *, -> or pointer arithmetic. Instead we use references and indices.

৭.১ Reference Basics

মনে রাখার কৌশল: অবজেক্ট/অ্যারে ভ্যারিয়েবলে রেফারেন্স থাকে। দুইটি রেফারেন্স একই অবজেক্টকে নির্দেশ করতে পারে।
Memory Tip: Object/array variables hold references. Two references can point to the same object.
Main.java
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int[] box = {a};
        int[] p = box;
        System.out.println("a এর মান = " + a);
        System.out.println("p[0] = " + p[0]);
        p[0] = 99;
        System.out.println("p দিয়ে বদলানোর পর box[0] = " + box[0]);
        System.out.println("p == box ? " + (p == box));
        System.out.println("a এর মান (অপরিবর্তিত) = " + a);
    }
}
a এর মান = 10 p[0] = 10 p দিয়ে বদলানোর পর box[0] = 99 p == box ? true a এর মান (অপরিবর্তিত) = 10

৭.২ Swap using References

মনে রাখার কৌশল: primitive এর address পাঠানো যায় না — অ্যারে পাঠিয়ে ভিতরের মান swap করো।
Memory Tip: Cannot pass address of primitives. Pass array and swap elements inside.
Main.java
public class Main {
    static void swapVals(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
    public static void main(String[] args) {
        int[] nums = {5, 10};
        swapVals(nums, 0, 1);
        System.out.println("a=" + nums[0] + ", b=" + nums[1]);
    }
}
a=10, b=5

৭.৩ Array with Index

মনে রাখার কৌশল: pointer arithmetic নেই — index ভ্যারিয়েবল দিয়ে arr[p + i] ব্যবহার করো।
Memory Tip: No pointer arithmetic — use an index variable: arr[p + i].
Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40};
        int p = 0;
        for (int i = 0; i < arr.length; i++)
            System.out.print(arr[p + i] + " ");
        System.out.println();
        for (int x : arr) System.out.print(x + " ");
        System.out.println();
    }
}
10 20 30 40 10 20 30 40

৭.৪ String Traversal

মনে রাখার কৌশল: '\\0' নেই — length() পর্যন্ত index দিয়ে charAt() করো।
Memory Tip: No '\\0' terminator — loop while p < str.length() and use charAt(p).
Main.java
public class Main {
    public static void main(String[] args) {
        String str = "Hello";
        int p = 0;
        while (p < str.length()) {
            System.out.print(str.charAt(p));
            p++;
        }
        System.out.println();
    }
}
