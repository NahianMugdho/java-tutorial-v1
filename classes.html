8. Structure & Union → Classes in Java

৮.১ Student Information

মনে রাখার কৌশল: struct নেই — class ব্যবহার করো। অবজেক্ট new দিয়ে তৈরি হয়। float লিটারেলে f দিতে হয় (3.85f)।
Memory Tip: No struct — use class. Create object with new. Float literals need f (3.85f).
Main.java
class Student {
    String name;
    int roll;
    float gpa;
    Student(String name, int roll, float gpa) {
        this.name = name;
        this.roll = roll;
        this.gpa = gpa;
    }
}
public class Main {
    public static void main(String[] args) {
        Student s1 = new Student("Mugdho", 101, 3.85f);
        System.out.println("নাম: " + s1.name + ", রোল: " + s1.roll + ", GPA: " + s1.gpa);
    }
}
নাম: Mugdho, রোল: 101, GPA: 3.85

৮.২ Employee Record

মনে রাখার কৌশল: Employee[] e = new Employee[2]; শুধু null রেফারেন্স তৈরি করে — প্রতিটিতে new দিতে হয়।
Memory Tip: new Employee[2] only creates null slots — you must new each element.
Main.java
class Employee {
    String name;
    int id;
    float salary;
    Employee(String name, int id, float salary) {
        this.name = name;
        this.id = id;
        this.salary = salary;
    }
}
public class Main {
    public static void main(String[] args) {
        Employee[] e = {
            new Employee("Karim", 1, 30000),
            new Employee("Rahim", 2, 35000)
        };
        for (int i = 0; i < e.length; i++)
            System.out.println("ID: " + e[i].id + ", নাম: " + e[i].name + ", বেতন: " + e[i].salary);
    }
}
ID: 1, নাম: Karim, বেতন: 30000.0 ID: 2, নাম: Rahim, বেতন: 35000.0

৮.৩ Nested Structure

মনে রাখার কৌশল: একটা ক্লাস আরেকটার ভিতরে ফিল্ড হিসেবে রাখা যায় — অ্যাক্সেস করতে . দুইবার লাগে।
Memory Tip: One class can be a field of another — access with double dot (e.joiningDate.day).
Main.java
class Date {
    int day, month, year;
    Date(int day, int month, int year) {
        this.day = day;
        this.month = month;
        this.year = year;
    }
}
class Employee {
    String name;
    Date joiningDate;
    Employee(String name, Date joiningDate) {
        this.name = name;
        this.joiningDate = joiningDate;
    }
}
public class Main {
    public static void main(String[] args) {
        Employee e1 = new Employee("Karim", new Date(15, 8, 2023));
        System.out.println("নাম: " + e1.name + ", যোগদান: " + e1.joiningDate.day + "/"
            + e1.joiningDate.month + "/" + e1.joiningDate.year);
    }
}
নাম: Karim, যোগদান: 15/8/2023

৮.৪ Union Example (ByteBuffer)

মনে রাখার কৌশল: Java তে union নেই। একই মেমরি ব্লক ভিন্ন টাইপে পড়তে ByteBuffer ব্যবহার করা যায়।
Memory Tip: No union in Java. Use ByteBuffer to share the same memory block with different types.
Main.java
import java.nio.ByteBuffer;

public class Main {
    public static void main(String[] args) {
        ByteBuffer data = ByteBuffer.allocate(20);
        data.putInt(0, 10);
        System.out.println("i = " + data.getInt(0));
        data.putFloat(0, 3.14f);
        System.out.println("f = " + data.getFloat(0));
        System.out.println("একই মেমরিকে int হিসেবে পড়লে = " + data.getInt(0));
        System.out.println("মেমরি ব্লকের আকার = " + data.capacity() + " bytes");
    }
}
i = 10 f = 3.14 একই মেমরিকে int হিসেবে পড়লে = 1078523331 মেমরি ব্লকের আকার = 20 bytes
