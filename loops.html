২. লুপ প্রোগ্রাম (Loop Programs)

2. Loop Programs

২.১ Sum of N numbers

মনে রাখার কৌশল: for লুপে sum += i — ১ থেকে n পর্যন্ত যোগ করো।
Memory Tip: In a for loop use sum += i from 1 to n.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("n দিন: ");
        int n = sc.nextInt(), sum = 0;
        for (int i = 1; i <= n; i++)
            sum += i;
        System.out.println("যোগফল = " + sum);
        sc.close();
    }
}
5
n দিন: যোগফল = 15

২.২ Factorial

মনে রাখার কৌশল: fact *= i, শুরুর মান ১। বড় ফ্যাক্টরিয়ালের জন্য long ব্যবহার করো।
Memory Tip: Use fact *= i, start with 1. Use long for larger factorials.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("n দিন: ");
        int n = sc.nextInt();
        long fact = 1;
        for (int i = 1; i <= n; i++)
            fact *= i;
        System.out.println(n + "! = " + fact);
        sc.close();
    }
}
5
n দিন: 5! = 120

২.৩ Fibonacci Series

মনে রাখার কৌশল: প্রথম দুইটা 0,1 — পরেরটা আগের দুইটার যোগফল।
Memory Tip: Start with 0,1 — each next term is sum of previous two.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("কতগুলো পদ চান: ");
        int n = sc.nextInt(), a = 0, b = 1, next;
        for (int i = 0; i < n; i++) {
            System.out.print(a + " ");
            next = a + b;
            a = b;
            b = next;
        }
        System.out.println();
        sc.close();
    }
}
8
কতগুলো পদ চান: 0 1 1 2 3 5 8 13

২.৪ Prime Number

মনে রাখার কৌশল: 2 থেকে sqrt(n) পর্যন্ত কোনো সংখ্যা দিয়ে ভাগ গেলে prime না। Math.sqrt() সরাসরি পাওয়া যায়।
Memory Tip: Check divisibility from 2 to sqrt(n). Use Math.sqrt().
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt();
        boolean isPrime = true;
        if (n <= 1) isPrime = false;
        for (int i = 2; i <= Math.sqrt(n); i++) {
            if (n % i == 0) { isPrime = false; break; }
        }
        System.out.println(n + " " + (isPrime ? "মৌলিক সংখ্যা (Prime)" : "মৌলিক সংখ্যা নয়"));
        sc.close();
    }
}
29
সংখ্যা দিন: 29 মৌলিক সংখ্যা (Prime)

২.৫ Prime numbers in a range

মনে রাখার কৌশল: প্রতিটি সংখ্যার জন্য prime-চেক মেথড বারবার কল করো। মেথডটি static হতে হয়।
Memory Tip: Call a static isPrime method for each number in the range.
Main.java
import java.util.Scanner;

public class Main {
    static boolean isPrime(int n) {
        if (n <= 1) return false;
        for (int i = 2; i * i <= n; i++)
            if (n % i == 0) return false;
        return true;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("শুরু ও শেষ দিন: ");
        int low = sc.nextInt(), high = sc.nextInt();
        System.out.print("মৌলিক সংখ্যাসমূহ: ");
        for (int i = low; i <= high; i++)
            if (isPrime(i)) System.out.print(i + " ");
        System.out.println();
        sc.close();
    }
}
10 30
শুরু ও শেষ দিন: মৌলিক সংখ্যাসমূহ: 11 13 17 19 23 29

২.৬ Perfect Number

মনে রাখার কৌশল: যে সংখ্যা তার প্রকৃত ভাজকগুলোর (নিজেকে বাদে) যোগফলের সমান (যেমন 6 = 1+2+3)।
Memory Tip: A number equal to the sum of its proper divisors (excluding itself), e.g. 6 = 1+2+3.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt(), sum = 0;
        for (int i = 1; i < n; i++)
            if (n % i == 0) sum += i;
        if (sum == n)
            System.out.println(n + " একটি পারফেক্ট নাম্বার");
        else
            System.out.println(n + " পারফেক্ট নাম্বার নয়");
        sc.close();
    }
}
28
সংখ্যা দিন: 28 একটি পারফেক্ট নাম্বার

২.৭ Armstrong Number

মনে রাখার কৌশল: প্রতিটি অংককে অংকসংখ্যার পাওয়ারে তুলে যোগ করো। Math.pow() double দেয় বলে (int) cast করো।
Memory Tip: Raise each digit to the power of digit count and sum. Cast Math.pow() result to int.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt();
        int original = n, remainder, digits = 0;
        double result = 0;
        for (int temp = n; temp != 0; temp /= 10) digits++;
        for (int temp = n; temp != 0; temp /= 10) {
            remainder = temp % 10;
            result += Math.pow(remainder, digits);
        }
        if ((int) result == original)
            System.out.println(original + " আর্মস্ট্রং সংখ্যা");
        else
            System.out.println(original + " আর্মস্ট্রং সংখ্যা নয়");
        sc.close();
    }
}
153
সংখ্যা দিন: 153 আর্মস্ট্রং সংখ্যা

২.৮ Palindrome Number

মনে রাখার কৌশল: সংখ্যাটি উল্টিয়ে মূল সংখ্যার সাথে মিলিয়ে দেখো।
Memory Tip: Reverse the number and compare with the original.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt();
        int original = n, reversed = 0, remainder;
        while (n != 0) {
            remainder = n % 10;
            reversed = reversed * 10 + remainder;
            n /= 10;
        }
        if (original == reversed)
            System.out.println(original + " প্যালিনড্রোম");
        else
            System.out.println(original + " প্যালিনড্রোম নয়");
        sc.close();
    }
}
121
সংখ্যা দিন: 121 প্যালিনড্রোম

২.৯ Reverse Number

মনে রাখার কৌশল: while লুপে শেষ অংক বের করে (n%10) নতুন সংখ্যায় বসাও, তারপর n/=10।
Memory Tip: Extract last digit with n%10, build reversed number, then n/=10.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt(), reversed = 0;
        while (n != 0) {
            reversed = reversed * 10 + n % 10;
            n /= 10;
        }
        System.out.println("উল্টানো সংখ্যা = " + reversed);
        sc.close();
    }
}
12345
সংখ্যা দিন: উল্টানো সংখ্যা = 54321

২.১০ Sum of Digits

মনে রাখার কৌশল: প্রতিবার n%10 যোগ করো এবং n/=10 করে ছোট করো।
Memory Tip: Add n%10 each time and shrink n with n/=10.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt(), sum = 0;
        while (n != 0) {
            sum += n % 10;
            n /= 10;
        }
        System.out.println("অংকের যোগফল = " + sum);
        sc.close();
    }
}
12345
সংখ্যা দিন: অংকের যোগফল = 15

২.১১ Count Digits

মনে রাখার কৌশল: প্রতিবার n/=10 করে একটা কাউন্টার বাড়াও।
Memory Tip: Increment a counter each time you do n/=10.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt(), count = 0;
        while (n != 0) {
            n /= 10;
            count++;
        }
        System.out.println("অংকের সংখ্যা = " + count);
        sc.close();
    }
}
12345
সংখ্যা দিন: অংকের সংখ্যা = 5

২.১২ GCD & LCM

মনে রাখার কৌশল: ইউক্লিডের অ্যালগরিদম — while(y != 0)। LCM = (a*b)/GCD। Java তে শর্ত অবশ্যই boolean।
Memory Tip: Euclidean algorithm — while(y != 0). LCM = (a*b)/GCD. Condition must be boolean.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("দুইটি সংখ্যা দিন: ");
        int a = sc.nextInt(), b = sc.nextInt();
        int x = a, y = b, temp;
        while (y != 0) {
            temp = y;
            y = x % y;
            x = temp;
        }
        int gcdVal = x;
        int lcmVal = (a * b) / gcdVal;
        System.out.println("GCD = " + gcdVal);
        System.out.println("LCM = " + lcmVal);
        sc.close();
    }
}
48 18
দুইটি সংখ্যা দিন: GCD = 6 LCM = 144
