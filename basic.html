১. বেসিক প্রোগ্রাম (Basic Programs)

1. Basic Programs

এখানে সবচেয়ে মৌলিক প্রোগ্রামগুলো আছে। প্রতিটি প্রোগ্রামে বাংলা কমেন্ট, মনে রাখার কৌশল এবং আসল আউটপুট দেওয়া আছে।

These are the most fundamental programs. Each includes Bangla comments, memory tricks, and real output.

১.১ Hello World

মনে রাখার কৌশল: Java তে সবকিছু class এর ভিতরে লিখতে হয়। public class এর নাম ফাইলের নামের সাথে হুবহু মিলতে হয় (Main.java)। প্রোগ্রাম শুরু হয় public static void main(String[] args) থেকে। C++ এর cout এর বদলে System.out.println() ব্যবহার হয়।
Memory Tip: Everything in Java must be inside a class. The public class name must exactly match the filename (Main.java). Program starts from public static void main(String[] args). Use System.out.println() instead of C++ cout.
Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World"); // স্ক্রিনে টেক্সট প্রিন্ট করে
    }
}
Hello World

১.২ Add, Subtract, Multiply, Divide

মনে রাখার কৌশল: ইনপুটের জন্য java.util.Scanner ক্লাস লাগে — Scanner sc = new Scanner(System.in); তারপর sc.nextInt() দিয়ে সংখ্যা পড়া যায়। ভাগের আগে দ্বিতীয় সংখ্যা শূন্য কিনা চেক করা ভালো অভ্যাস।
Memory Tip: Use java.util.Scanner for input — Scanner sc = new Scanner(System.in); then sc.nextInt(). Always check for division by zero.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("দুইটি সংখ্যা দিন: ");
        int a = sc.nextInt();
        int b = sc.nextInt();
        System.out.println("যোগফল = " + (a + b));
        System.out.println("বিয়োগফল = " + (a - b));
        System.out.println("গুণফল = " + (a * b));
        if (b != 0)
            System.out.println("ভাগফল = " + (float) a / b);
        else
            System.out.println("ভাগফল সংজ্ঞায়িত নয় (b=0)");
        sc.close();
    }
}
10 3
দুইটি সংখ্যা দিন: যোগফল = 13 বিয়োগফল = 7 গুণফল = 30 ভাগফল = 3.3333333

১.৩ Swap two numbers (with/without third variable)

মনে রাখার কৌশল: তৃতীয় ভ্যারিয়েবল ছাড়া swap করতে হলে যোগ-বিয়োগ অথবা XOR ব্যবহার করা যায়।
Memory Tip: Without a third variable, use addition-subtraction or XOR method.
Main.java
public class Main {
    public static void main(String[] args) {
        int a = 5, b = 10, temp;

        // ---- তৃতীয় ভ্যারিয়েবল দিয়ে ----
        temp = a;
        a = b;
        b = temp;
        System.out.println("তৃতীয় ভ্যারিয়েবল দিয়ে: a=" + a + ", b=" + b);

        // ---- তৃতীয় ভ্যারিয়েবল ছাড়া (যোগ-বিয়োগ) ----
        a = 5; b = 10;
        a = a + b;
        b = a - b;
        a = a - b;
        System.out.println("ছাড়া (যোগ-বিয়োগ): a=" + a + ", b=" + b);

        // ---- XOR পদ্ধতি ----
        a = 5; b = 10;
        a = a ^ b;
        b = a ^ b;
        a = a ^ b;
        System.out.println("XOR পদ্ধতি: a=" + a + ", b=" + b);
    }
}
তৃতীয় ভ্যারিয়েবল দিয়ে: a=10, b=5 ছাড়া (যোগ-বিয়োগ): a=10, b=5 XOR পদ্ধতি: a=10, b=5

১.৪ Even / Odd

মনে রাখার কৌশল: % (মডুলাস) দিয়ে ২ দিয়ে ভাগশেষ বের করো — শূন্য হলে জোড়। Java তে if এর শর্ত অবশ্যই boolean হতে হয়।
Memory Tip: Use % (modulo) — if remainder is 0 when divided by 2, it's even. Condition in if must be boolean.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt();
        if (n % 2 == 0)
            System.out.println(n + " জোড় (Even)");
        else
            System.out.println(n + " বিজোড় (Odd)");
        sc.close();
    }
}
7
সংখ্যা দিন: 7 বিজোড় (Odd)

১.৫ Positive / Negative / Zero

মনে রাখার কৌশল: তিনটি শর্ত — >0, <0, ==0 — if-else if-else চেইন দিয়ে চেক করো।
Memory Tip: Check three conditions with if-else if-else chain.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সংখ্যা দিন: ");
        int n = sc.nextInt();
        if (n > 0)
            System.out.println("ধনাত্মক (Positive)");
        else if (n < 0)
            System.out.println("ঋণাত্মক (Negative)");
        else
            System.out.println("শূন্য (Zero)");
        sc.close();
    }
}
-5
সংখ্যা দিন: ঋণাত্মক (Negative)

১.৬ Largest of 2/3 numbers

মনে রাখার কৌশল: a >= b && a >= c হলে a সবচেয়ে বড়। শর্টকাট: Math.max(a, Math.max(b, c))
Memory Tip: Use a >= b && a >= c. Shortcut: Math.max(a, Math.max(b, c))
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("তিনটি সংখ্যা দিন: ");
        int a = sc.nextInt(), b = sc.nextInt(), c = sc.nextInt();
        if (a >= b && a >= c)
            System.out.println("সবচেয়ে বড়: " + a);
        else if (b >= a && b >= c)
            System.out.println("সবচেয়ে বড়: " + b);
        else
            System.out.println("সবচেয়ে বড়: " + c);
        sc.close();
    }
}
12 45 7
তিনটি সংখ্যা দিন: সবচেয়ে বড়: 45

১.৭ Leap Year

মনে রাখার কৌশল: নিয়ম — (৪ দিয়ে বিভাজ্য এবং ১০০ দিয়ে বিভাজ্য নয়) অথবা (৪০০ দিয়ে বিভাজ্য)।
Memory Tip: Rule: (divisible by 4 and not by 100) OR (divisible by 400).
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("সাল দিন: ");
        int y = sc.nextInt();
        if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0))
            System.out.println(y + " অধিবর্ষ (Leap Year)");
        else
            System.out.println(y + " অধিবর্ষ নয়");
        sc.close();
    }
}
2024
সাল দিন: 2024 অধিবর্ষ (Leap Year)

১.৮ Vowel / Consonant

মনে রাখার কৌশল: a,e,i,o,u (ছোট/বড়) — এই ৫টা অক্ষর হলে vowel। Java তে char পড়তে sc.next().charAt(0) ব্যবহার করো।
Memory Tip: a,e,i,o,u (both cases) are vowels. Read char with sc.next().charAt(0).
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("একটি অক্ষর দিন: ");
        char ch = sc.next().charAt(0);
        if (ch=='a'||ch=='e'||ch=='i'||ch=='o'||ch=='u'||
            ch=='A'||ch=='E'||ch=='I'||ch=='O'||ch=='U')
            System.out.println("স্বরবর্ণ (Vowel)");
        else
            System.out.println("ব্যঞ্জনবর্ণ (Consonant)");
        sc.close();
    }
}
e
একটি অক্ষর দিন: স্বরবর্ণ (Vowel)

১.৯ Grade Calculation

মনে রাখার কৌশল: নাম্বার অনুযায়ী রেঞ্জ ধরে if-else if চেইন, সবচেয়ে বড় শর্ত আগে চেক করা ভালো।
Memory Tip: Use if-else if chain based on mark ranges. Check highest range first.
Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("নম্বর দিন: ");
        int marks = sc.nextInt();
        if (marks >= 80) System.out.println("গ্রেড: A+");
        else if (marks >= 70) System.out.println("গ্রেড: A");
        else if (marks >= 60) System.out.println("গ্রেড: A-");
        else if (marks >= 50) System.out.println("গ্রেড: B");
        else if (marks >= 40) System.out.println("গ্রেড: C");
        else if (marks >= 33) System.out.println("গ্রেড: D");
        else System.out.println("গ্রেড: F (ফেল)");
        sc.close();
    }
}
75
নম্বর দিন: গ্রেড: A
