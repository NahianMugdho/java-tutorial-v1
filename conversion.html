সংক্ষেপে মনে রাখার নিয়ম (C++ → Java)

Quick Rules (C++ → Java)

  • সবকিছু class এর ভিতরে
  • cout/cin → System.out / Scanner
  • স্ট্রিং তুলনায় অবশ্যই .equals()
  • sizeof → .length / .length()
  • new/delete → শুধু new, GC নিজে ফ্রি করে
  • পয়েন্টার/struct → রেফারেন্স ও class
  • Everything inside a class
  • cout/cin → System.out / Scanner
  • Always use .equals() for strings
  • sizeof → .length / .length()
  • new/delete → only new, GC frees
  • Pointers/struct → references & class

সবচেয়ে বেশি হওয়া ভুলসমূহ

Most Common Mistakes

  • স্ট্রিং তুলনায় == ব্যবহার → সবসময় .equals()
  • while (n) → while (n != 0)
  • arr.length vs str.length() গুলিয়ে ফেলা
  • float x = 3.85; → 3.85f লিখতে হয়
  • main থেকে non-static মেথড ডাকা
  • public class নাম ≠ ফাইলের নাম
  • লোকাল ভ্যারিয়েবল ইনিশিয়ালাইজ না করা
