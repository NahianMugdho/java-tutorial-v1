6. Function (Method) Programs

৬.১ Recursive Factorial

মনে রাখার কৌশল: বেস কেস n<=1 হলে return 1, নাহলে n * fact(n-1)। মেথড static হতে হয়।
Memory Tip: Base case: n<=1 return 1, else n * fact(n-1). Method must be static.
Main.java
public class Main {
    static long fact(int n) {
        if (n <= 1) return 1;
        return n * fact(n - 1);
    }
    public static void main(String[] args) {
        int n = 5;
        System.out.println(n + "! = " + fact(n));
    }
}
5! = 120

৬.২ Recursive Fibonacci

মনে রাখার কৌশল: বেস কেস n==0 বা n==1, নাহলে fib(n-1) + fib(n-2)।
Memory Tip: Base: n==0 or 1, else fib(n-1) + fib(n-2).
Main.java
public class Main {
    static int fib(int n) {
        if (n == 0) return 0;
        if (n == 1) return 1;
        return fib(n - 1) + fib(n - 2);
    }
    public static void main(String[] args) {
        int n = 8;
        for (int i = 0; i < n; i++)
            System.out.print(fib(i) + " ");
        System.out.println();
    }
}
0 1 1 2 3 5 8 13

৬.৩ Recursive GCD

মনে রাখার কৌশল: gcd(a,b) = gcd(b, a%b), b==0 হলে a।
Memory Tip: gcd(a,b) = gcd(b, a%b), when b==0 return a.
Main.java
public class Main {
    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
    public static void main(String[] args) {
        System.out.println("GCD = " + gcd(48, 18));
    }
}
GCD = 6

৬.৪ Call by Value vs Call by Reference

মনে রাখার কৌশল: Java তে সবসময় Call by Value। primitive কপি যায়। অ্যারে/অবজেক্ট পাঠালে রেফারেন্সের কপি যায় — ভিতরের ডেটা বদলালে মূল বদলায়।
Memory Tip: Java is always Call by Value. Primitives are copied. Arrays/objects pass a copy of the reference — modifying contents affects original.
Main.java
public class Main {
    static void byValue(int x) {
        x = x + 10;
    }
    static void byArray(int[] x) {
        x[0] = x[0] + 10;
    }
    public static void main(String[] args) {
        int a = 5;
        byValue(a);
        System.out.println("byValue এর পর a = " + a + " (অপরিবর্তিত)");
        int[] box = {5};
        byArray(box);
        System.out.println("byArray এর পর box[0] = " + box[0] + " (পরিবর্তিত)");
    }
}
byValue এর পর a = 5 (অপরিবর্তিত) byArray এর পর box[0] = 15 (পরিবর্তিত)
