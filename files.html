৯. ফাইল হ্যান্ডলিং (File Handling)

9. File Handling

৯.১ Write to File

মনে রাখার কৌশল: FileWriter + PrintWriter। try-with-resources ব্যবহার করলে close() লাগে না। IOException হ্যান্ডেল বাধ্যতামূলক।
Memory Tip: FileWriter + PrintWriter. try-with-resources auto-closes. Must handle IOException.
Main.java
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;

public class Main {
    public static void main(String[] args) {
        try (PrintWriter fout = new PrintWriter(new FileWriter("data.txt"))) {
            fout.println("Hello, this is a test file.");
            System.out.println("ফাইলে লেখা হয়েছে");
        } catch (IOException e) {
            System.out.println("ফাইল খোলা যায়নি");
        }
    }
}
ফাইলে লেখা হয়েছে

৯.২ Read from File

মনে রাখার কৌশল: BufferedReader + FileReader। readLine() শেষে null দেয়।
Memory Tip: BufferedReader + FileReader. readLine() returns null at end of file.
Main.java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) {
        try (BufferedReader fin = new BufferedReader(new FileReader("data.txt"))) {
            String line;
            while ((line = fin.readLine()) != null)
                System.out.println(line);
        } catch (IOException e) {
            System.out.println("ফাইল খোলা যায়নি");
        }
    }
}
Hello, this is a test file.

৯.৩ Append File

মনে রাখার কৌশল: FileWriter এর দ্বিতীয় আর্গুমেন্ট true দিলে append mode।
Memory Tip: Pass true as second argument to FileWriter for append mode.
Main.java
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;

public class Main {
    public static void main(String[] args) {
        try (PrintWriter fout = new PrintWriter(new FileWriter("data.txt", true))) {
            fout.println("নতুন লাইন যোগ করা হলো।");
            System.out.println("ফাইলে যোগ করা হয়েছে");
        } catch (IOException e) {
            System.out.println("ফাইল খোলা যায়নি");
        }
    }
}
ফাইলে যোগ করা হয়েছে

৯.৪ Copy File

মনে রাখার কৌশল: FileInputStream / FileOutputStream দিয়ে বাইট বাইট কপি — যেকোনো ফাইল হুবহু কপি হয়।
Memory Tip: Use FileInputStream / FileOutputStream to copy byte by byte — works for any file type.
Main.java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) {
        try (FileInputStream src = new FileInputStream("data.txt");
             FileOutputStream dest = new FileOutputStream("copy.txt")) {
            int ch;
            while ((ch = src.read()) != -1)
                dest.write(ch);
            System.out.println("ফাইল কপি সম্পন্ন");
        } catch (IOException e) {
            System.out.println("ফাইল খোলা যায়নি");
        }
    }
}
ফাইল কপি সম্পন্ন
