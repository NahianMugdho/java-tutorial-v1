How to Compile & Run

  1. প্রতিটি প্রোগ্রাম Main.java নামে সেভ করো — ক্লাসের নাম Main হতে হবে।
  2. Save every program as Main.java — the class name must be Main.
  3. কম্পাইল: javac Main.java (সফল হলে Main.class তৈরি হয়)
  4. Compile: javac Main.java (creates Main.class on success)
  5. রান: java Main
  6. Run: java Main
  7. উইন্ডোজে বাংলা না দেখালে: java -Dfile.encoding=UTF-8 Main অথবা আগে chcp 65001
  8. If Bangla doesn't show on Windows: use java -Dfile.encoding=UTF-8 Main or run chcp 65001 first.
