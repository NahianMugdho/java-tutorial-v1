৫. স্ট্রিং প্রোগ্রাম (String Programs)

5. String Programs

৫.১ String Length (manual)

মনে রাখার কৌশল: String immutable। দৈর্ঘ্য পেতে str.length() (ব্র্যাকেট সহ)। অ্যারের .length এর সাথে গুলিয়ে ফেলো না।
Memory Tip: String is immutable. Use str.length() (with parentheses). Don't confuse with array's .length.
Main.java
public class Main {
    public static void main(String[] args) {
        String str = "Bangladesh";
        int len = 0;
        for (char c : str.toCharArray()) len++;
        System.out.println("দৈর্ঘ্য = " + len);
    }
}
দৈর্ঘ্য = 10

৫.২ String Copy

মনে রাখার কৌশল: = দিয়ে রেফারেন্স কপি হয়। নতুন অবজেক্ট চাইলে new String(src)।
Memory Tip: = copies the reference. Use new String(src) for a new object.
Main.java
public class Main {
    public static void main(String[] args) {
        String src = "Hello";
        String dest = src;
        String copy = new String(src);
        System.out.println("কপি করা স্ট্রিং: " + dest);
        src = "World";
        System.out.println("src = " + src + ", dest = " + dest + ", copy = " + copy);
    }
}
কপি করা স্ট্রিং: Hello src = World, dest = Hello, copy = Hello

৫.৩ String Compare

মনে রাখার কৌশল: মান তুলনায় অবশ্যই .equals() ব্যবহার করো — == নয়! == শুধু রেফারেন্স দেখে।
Memory Tip: Always use .equals() for content comparison. == only checks reference equality.
Main.java
public class Main {
    public static void main(String[] args) {
        String s1 = "abc", s2 = "abd";
        boolean isEqual = s1.equals(s2);
        System.out.println(isEqual ? "স্ট্রিং সমান" : "স্ট্রিং ভিন্ন");
        System.out.println("compareTo = " + s1.compareTo(s2));
        String a = "abc";
        String b = new String("abc");
        System.out.println("a == b : " + (a == b));
        System.out.println("a.equals(b) : " + a.equals(b));
    }
}
স্ট্রিং ভিন্ন compareTo = -1 a == b : false a.equals(b) : true

৫.৪ String Reverse

মনে রাখার কৌশল: String immutable বলে toCharArray() করে swap করো। শর্টকাট: new StringBuilder(str).reverse().toString()
Memory Tip: Convert to char array, swap, then new String. Shortcut: StringBuilder reverse.
Main.java
public class Main {
    public static void main(String[] args) {
        String str = "Bangladesh";
        char[] arr = str.toCharArray();
        int len = arr.length;
        for (int i = 0, j = len - 1; i < j; i++, j--) {
            char t = arr[i];
            arr[i] = arr[j];
            arr[j] = t;
        }
        System.out.println("উল্টানো স্ট্রিং: " + new String(arr));
    }
}
উল্টানো স্ট্রিং: hsedalgnaB

৫.৫ Palindrome String

মনে রাখার কৌশল: দুই প্রান্ত থেকে তুলনা করো। অক্ষর অ্যাক্সেস: str.charAt(i)
Memory Tip: Compare characters from both ends. Access with str.charAt(i)
Main.java
public class Main {
    public static void main(String[] args) {
        String str = "madam";
        int len = str.length();
        boolean isPalindrome = true;
        for (int i = 0; i < len / 2; i++)
            if (str.charAt(i) != str.charAt(len - 1 - i)) {
                isPalindrome = false; break;
            }
        System.out.println(isPalindrome ? "প্যালিনড্রোম" : "প্যালিনড্রোম নয়");
    }
}
প্যালিনড্রোম

৫.৬ Count Vowels/Consonants

মনে রাখার কৌশল: Character.toLowerCase(ch) ব্যবহার করো।
Memory Tip: Use Character.toLowerCase(ch) for case-insensitive check.
Main.java
public class Main {
    public static void main(String[] args) {
        String str = "Bangladesh";
        int vowels = 0, consonants = 0;
        for (char ch : str.toCharArray()) {
            ch = Character.toLowerCase(ch);
            if (ch=='a'||ch=='e'||ch=='i'||ch=='o'||ch=='u') vowels++;
            else if (ch >= 'a' && ch <= 'z') consonants++;
        }
        System.out.println("স্বরবর্ণ = " + vowels + ", ব্যঞ্জনবর্ণ = " + consonants);
    }
}
স্বরবর্ণ = 3, ব্যঞ্জনবর্ণ = 7

৫.৭ Count Words

মনে রাখার কৌশল: স্পেস থেকে non-space এ ট্রানজিশন হলেই নতুন শব্দ।
Memory Tip: Count a new word on transition from space to non-space.
Main.java
public class Main {
    public static void main(String[] args) {
        String str = "I love Bangladesh";
        int count = 0;
        for (int i = 0; i < str.length(); i++)
            if (str.charAt(i) != ' ' && (i == 0 || str.charAt(i - 1) == ' '))
                count++;
        System.out.println("শব্দ সংখ্যা = " + count);
    }
}
শব্দ সংখ্যা = 3

৫.৮ Character Frequency

মনে রাখার কৌশল: freq[26] অ্যারে রাখো। new int[26] নিজে থেকেই 0 হয়।
Memory Tip: Use freq[26] array. new int[26] is automatically zero-filled.
Main.java
public class Main {
    public static void main(String[] args) {
        String str = "programming";
        int[] freq = new int[26];
        for (char ch : str.toCharArray())
            freq[Character.toLowerCase(ch) - 'a']++;
        for (int i = 0; i < 26; i++)
            if (freq[i] > 0)
                System.out.println((char) ('a' + i) + ": " + freq[i] + " বার");
    }
}
a: 1 বার g: 2 বার i: 1 বার m: 2 বার n: 1 বার o: 1 বার p: 1 বার r: 2 বার
