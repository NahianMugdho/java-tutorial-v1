0. Java Beginner Tutorial (Complete Beginner Guide)

যদি তুমি জাভা একেবারে নতুন হও, তাহলে এই পেজটা আগে পড়ো। এখানে ব্যাখ্যা করা হয়েছে — জাভা কী, কেন শেখবে, কীভাবে কাজ করে, এবং একটি প্রোগ্রামের বেসিক স্ট্রাকচার।

If you are completely new to Java, read this page first. It explains what Java is, why you should learn it, how it works, and the basic structure of a Java program.

১. জাভা কী? / What is Java?

জাভা (Java) একটি অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং ল্যাঙ্গুয়েজ। এটি ১৯৯৫ সালে সান মাইক্রোসিস্টেমস (এখন ওরাকল) তৈরি করে। জাভার সবচেয়ে বড় বৈশিষ্ট্য হলো — “Write Once, Run Anywhere”। অর্থাৎ একবার কোড লিখলে যেকোনো অপারেটিং সিস্টেমে (Windows, Linux, Mac, Android) চালানো যায়।

Java is an object-oriented programming language created by Sun Microsystems (now Oracle) in 1995. Its biggest strength is “Write Once, Run Anywhere” — you write the code once and it can run on any operating system (Windows, Linux, Mac, Android).

২. জাভা কেন শিখবে? কোন কাজে ব্যবহার হয়? / Why Learn Java? Where is it used?

জাভা মূলত যেসব কাজে ব্যবহার হয়:

  • অ্যান্ড্রয়েড অ্যাপ ডেভেলপমেন্ট — পৃথিবীর সবচেয়ে জনপ্রিয় মোবাইল অ্যাপের ভাষা (Kotlin এর সাথে)
  • ব্যাংকিং ও এন্টারপ্রাইজ সফটওয়্যার — বড় বড় কোম্পানি, ব্যাংক, সরকারি সিস্টেম
  • ওয়েব ব্যাকএন্ড — Spring Boot ফ্রেমওয়ার্ক দিয়ে শক্তিশালী API ও সার্ভার
  • বড় ডেটা ও ক্লাউড — Hadoop, Apache Kafka, AWS, Google Cloud
  • ডেস্কটপ অ্যাপ্লিকেশন — Swing / JavaFX দিয়ে
  • গেম ডেভেলপমেন্ট — কিছু গেম ইঞ্জিনে ব্যবহার হয়

কেন শিখবে?

  • চাকরির বাজারে অনেক ডিমান্ড
  • সিনট্যাক্স পরিষ্কার ও শেখার জন্য ভালো
  • একবার শিখলে অন্যান্য ভাষা (C#, Kotlin, JavaScript) শিখতে সহজ হয়
  • বড় স্কেলের সফটওয়্যার বানানোর জন্য নির্ভরযোগ্য

Main uses of Java:

  • Android App Development — one of the most popular languages for mobile apps (along with Kotlin)
  • Banking & Enterprise Software — large companies, banks, government systems
  • Web Backend — powerful APIs and servers with Spring Boot
  • Big Data & Cloud — Hadoop, Apache Kafka, AWS, Google Cloud
  • Desktop Applications — using Swing / JavaFX
  • Game Development — used in some game engines

Why learn it?

  • High demand in job market
  • Clean syntax, good for beginners
  • Makes learning other languages (C#, Kotlin, JS) easier
  • Very reliable for large-scale software

৩. জাভা কীভাবে কাজ করে? / How does Java work?

  1. তুমি .java ফাইলে কোড লেখো।
  2. javac কম্পাইলার সেটাকে bytecode (.class ফাইল) এ রূপান্তর করে।
  3. যেকোনো কম্পিউটারে JVM (Java Virtual Machine) থাকলে সেই bytecode চালাতে পারে।

এজন্যই একই কোড Windows, Linux, Mac সব জায়গায় চলে।

  1. You write code in a .java file.
  2. The javac compiler converts it into bytecode (.class file).
  3. Any computer that has a JVM (Java Virtual Machine) can run that bytecode.

That’s why the same code runs on Windows, Linux, and Mac.

৪. একটি জাভা প্রোগ্রামের বেসিক স্ট্রাকচার / Basic Structure of a Java Program

খুব গুরুত্বপূর্ণ: জাভাতে সবকিছু একটা class এর ভিতরে থাকতে হয়। public class এর নাম অবশ্যই ফাইলের নামের সাথে মিলতে হবে।
Very important: Everything in Java must be inside a class. The public class name must match the filename.
Main.java — সবচেয়ে ছোট প্রোগ্রাম
// এটি একটি কমেন্ট — কম্পিউটার এটা পড়ে না

public class Main {                          // ক্লাসের শুরু
    public static void main(String[] args) { // প্রোগ্রাম এখান থেকে শুরু হয়
        System.out.println("Hello World");   // স্ক্রিনে কিছু প্রিন্ট করে
    }                                        // main মেথড শেষ
}                                            // ক্লাস শেষ

প্রতিটি অংশের অর্থ:

  • public class Main → ক্লাসের নাম Main (ফাইলের নামও Main.java হতে হবে)
  • public static void main(String[] args) → প্রোগ্রামের শুরুর পয়েন্ট। JVM এখান থেকে কোড চালায়।
  • System.out.println(...) → স্ক্রিনে টেক্সট দেখায় এবং নতুন লাইনে যায়।

Meaning of each part:

  • public class Main → Class name is Main (filename must be Main.java)
  • public static void main(String[] args) → Starting point of the program. JVM starts here.
  • System.out.println(...) → Prints text on screen and moves to a new line.

৫. কীভাবে কম্পাইল ও রান করবে / How to Compile & Run

  1. কোড Main.java নামে সেভ করো।
  2. টার্মিনাল / কমান্ড প্রম্পটে লেখো: javac Main.java
  3. সফল হলে Main.class ফাইল তৈরি হবে।
  4. তারপর রান করো: java Main

উইন্ডোজে বাংলা না দেখালে আগে chcp 65001 চালাও, অথবা java -Dfile.encoding=UTF-8 Main ব্যবহার করো।

  1. Save the code as Main.java.
  2. In terminal / command prompt type: javac Main.java
  3. If successful, Main.class will be created.
  4. Then run: java Main

If Bangla does not show on Windows, first run chcp 65001 or use java -Dfile.encoding=UTF-8 Main.

৬. ভ্যারিয়েবল ও ডেটা টাইপ / Variables & Data Types

ভ্যারিয়েবল মানে হলো ডেটা রাখার বাক্স। জাভাতে টাইপ বলে দিতে হয়।

A variable is a box that stores data. In Java you must declare the type.

Common Data Types
int age = 20;           // পূর্ণসংখ্যা (whole number)
double price = 99.50;   // দশমিক সংখ্যা
float gpa = 3.85f;      // ছোট দশমিক (শেষে f লাগে)
char grade = 'A';       // একটি অক্ষর
boolean isPass = true;  // true অথবা false
String name = "Mugdho"; // টেক্সট (বড় হাতের S)

৭. ইউজার ইনপুট নেওয়া / Taking User Input

Main.java
import java.util.Scanner;   // Scanner ক্লাস ইমপোর্ট করতে হয়

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);  // ইনপুট নেওয়ার জন্য অবজেক্ট

        System.out.print("তোমার নাম লেখো: ");
        String name = sc.nextLine();          // পুরো লাইন পড়ে

        System.out.print("তোমার বয়স লেখো: ");
        int age = sc.nextInt();               // পূর্ণসংখ্যা পড়ে

        System.out.println("হ্যালো " + name + ", তোমার বয়স " + age);

        sc.close();                           // ব্যবহার শেষে বন্ধ করা ভালো
    }
}

৮. শর্ত ও লুপ (বেসিক) / Conditions & Loops (Basic)

if-else & for loop
// if-else
int marks = 75;
if (marks >= 80) {
    System.out.println("A+");
} else if (marks >= 40) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}

// for loop — ১ থেকে ৫ পর্যন্ত প্রিন্ট
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

// while loop
int n = 3;
while (n > 0) {
    System.out.println(n);
    n--;
}
